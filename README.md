# pyNOMIC
## A pipeline for reducing data from LBTI-NOMIC

# Installation:

```
git clone https://github.com/vivekv7323/pyNOMIC.git
cd pyNOMIC
pip install -e .
```

# Running (examples): 

Check the notebooks folder for python notebooks for both single-sided
and double-sided reductions. A Read the Docs page is coming soon.
